## 説明文（4,000字以内）

```
奈良の参道は、鹿のフンだらけです。

下を見て歩けば、フンは避けられます。
でも前から鹿が来ます。

『下ばっか見てると』は、それだけのゲームです。
片手で、親指ひとつ。1回30秒。

■ フンのすぐそばを通ると、点が伸びる
避けるだけなら誰でもできます。
このゲームで点が伸びるのは、フンの「すぐ横」をかすめたとき。
安全に歩けば無傷ですが、稼げません。
攻めれば倍以上稼げますが、いずれ踏みます。

■ 空いている道が、正しい道とはかぎらない
フンはただ、ランダムに落ちています。安全な道は用意されていません。
空いて見えた筋が数歩先で行き止まることもあります。
広いほうへ逃げるか、狭い隙間を抜けるかは、そのつど自分で決めます。

■ 詰んだら、跳ぶ
指を離すとジャンプします。ボタンはありません。
跳べるのはフンだけ。鹿は跳んでも当たります。
続けて3回まで。使い切ると、ゲージが戻るまで7秒ほど歩いて耐えます。
たまに落ちている新しいくつを拾うと、汚れがひとつ落ちます。

■ 鹿せんべいは、盾であり、足かせでもある
売り場を通ると10枚もらえます。
持っているあいだは、鹿にぶつかっても1枚渡してやり過ごせます。
ただし群れに触れると囲まれ、枚数が尽きるまで動けません。
たくさん持っているほど、捕まったときが長い。

■ 100面 ＋ エンドレス
・ステージ：10エリア×10面。汚れの少なさで★が付きます
・エンドレス：どこまでも。だんだん速く、濃くなります
・記録はこの端末の中だけに残ります

■ 全部ドット絵、全部この中で
画像も音も、ひとつも同梱していません。すべてその場で作っています。
だから軽く、通信もいりません。電波の無いところでも遊べます。

奈良で実際に見た光景から作りました。
子どもが下を向いてフンを避けながら歩いていて、
顔を上げたら目の前に鹿がいた——あの一瞬のことです。
```

## スクリーンショット

**6.9インチ（1320×2868 か 1290×2796）が最低1枚あれば、他のサイズは自動で流用される。**
3〜5枚あると十分。撮るべき場面:

1. エンドレスのプレイ中（フンが濃い、レベル5以上）
   ※ バナーが写り込んでも問題ない。むしろ実際の画面と一致する
2. 鹿の群れが正面から来ているところ
3. 鹿せんべいを持って囲まれているところ（`swarm` 表示が出ている）
4. ステージ選択（★が並んでいるところ）
5. リザルト（ランキングに入ったところ）

実機で撮る（電源＋音量アップ）。Mac が無くてもよい——
iPhone で撮ったスクリーンショットをそのまま App Store Connect に上げられる。

> **加工した画像を出さないこと。** 実際の画面と違うと差し戻される。
> 文字を重ねるのは可（多くのゲームがやっている）だが、UI の捏造は不可。

## 審査メモ（App Review Information）

```
このアプリはアカウント登録もログインも必要ありません。
起動してすぐ遊べます。

広告について:
- Google AdMob のバナー・リワード動画・インタースティシャルを表示します
- バナーは画面のいちばん上にのみ表示し、操作領域には重なりません
- リワード動画は「見て つづける」をユーザーが押したときだけ再生されます
- 広告は1回目のプレイを終えてから表示を開始します
- 広告を見なくても、すべてのステージとモードが遊べます

ATT のダイアログは、起動直後ではなく1回プレイを終えたあとに表示されます。
拒否された場合はパーソナライズされていない広告を表示します。
```

## 出したあとに直しやすい順

| 変えたいもの | 審査 |
|---|---|
| プロモーションテキスト | **不要**（すぐ反映） |
| 説明文・キーワード・スクリーンショット | 次のバージョン提出時 |
| App 名・サブタイトル | 次のバージョン提出時 |
| バンドルID | **変えられない** |
| 販売者名 | 変えられない（法人化すると別アカウント扱い） |
