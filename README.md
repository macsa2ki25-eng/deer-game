# 下ばっか見てると / Mind the Deer

鹿のフンを避けて参道を歩く、16bit風の縦スクロール避けゲー。
これは **P0（エンドレスのみ）** の実装。100ステージは P2〜P3 で足す。

設計の全体像は [`../docs/DEER_GAME_DESIGN.md`](../docs/DEER_GAME_DESIGN.md)。
このコードの定数は仕様書の数字と1対1で対応しているので、**片方だけ直さないこと**。

## 動かす

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # 型チェック + dist/ に出力
npm run typecheck
```

`?debug=1` を付けて開くと `window.__mtd` に内部状態が出る。バランス調整の自動テストがここを使う。

## 画面の構成

縦持ちの2段。**指がゲーム画面に一切かからない**のが肝。

```
┌──────────────┐
│              │  上段：ゲーム画面（canvas 160×176、整数倍拡大）
│   ゲーム画面   │  参道は x 16〜144（8タイル）
│              │  プレイヤーは y 20〜160
├──────────────┤
│ スコア／倍率  │  下段：DOM
│ きょり／汚れ  │
│              │
│  操作パッド   │  なぞった位置がそのまま目標位置（絶対指定）
│              │  ワープはしない。移動速度は LATERAL で頭打ち
└──────────────┘
```

## 遊びの芯

- **フンのすぐそば（8px以内）を通ると「グレイズ」**。倍率ゲージが溜まる
- ゲージは指数で減衰するので、釣り合い点 = 毎秒のグレイズ数 × GAIN ÷ DECAY
- **安全に歩けば無傷だが稼げない。フンを舐めれば9倍稼げるが死ぬ**
- 汚れ5でゲームオーバー（フン+1、鹿+2）

## 理不尽にしないための仕掛け

`level.ts` が全部持っている。

1. **安全回廊**：先に幅24pxの通れる道を引いてから、その外側にだけフンを置く
2. 回廊が1行でずれる量は `DRIFT_SAFETY × LATERAL / v` に制限
   （理論上限をそのまま使うと余裕がゼロになり、実測で破綻した）
3. 粒は行の基準yからずれて落ちるので、**ずれたぶんだけ余分に空ける**
   （これを忘れると「1行ぶん古い回廊」の位置に粒が乗って道が塞がる）
4. 鹿は画面に入る0.5秒前に予兆を出す。牡鹿はさらに0.8秒ためる
5. 速度の上限は**画面の縦幅から逆算**する。反応時間の下限1.2秒を固定して割り戻す

## ファイル

| | |
|---|---|
| `config.ts` | 定数と難易度カーブ。仕様書と1対1 |
| `state.ts` | 状態の型と初期化 |
| `level.ts` | 安全回廊とフン・鹿の生成 |
| `game.ts` | 1フレームの更新（移動・当たり・グレイズ・スコア） |
| `render.ts` | 上段の描画のみ |
| `sprites.ts` | ドット絵（文字列＝ピクセル）。仮絵 |
| `background.ts` | 参道と植え込みのストリップ生成 |
| `input.ts` | パッドとキーボード |
| `audio.ts` | 矩形波・ノイズの実行時合成（音源ファイル不要） |
| `main.ts` | 起動・画面合わせ・ループ・下段UI |

素材ファイルはゼロ。ビルド出力は index.html + js のみで **完全オフライン**。
