# 下ばっか見てると / Mind the Deer

奈良公園。子どもが鹿のフンを避けて歩く。ただそれだけのゲーム。

**指がやることは、押すか離すかだけ。**

```
おしてる  → 下を見る。足元の小さいフンを避ける。でも前の鹿が見えない。足が遅い
はなす    → 前を見る。鹿をよける。速く走れる。でも足元を踏む
```

どっちも同時には見られない。それだけの遊び。

**でかいフンだけは、とびこえる。**とぶには助走が要るので、
うつむいた ちょこちょこ歩きでは跳べない——顔を上げているあいだにしか越えられない。
そして**どこに来るかは、下を向かないと見えない**。
覚えて、目を切って、跳ぶ。ここがいちばんの山。

```bash
npm install
npm run dev      # ブラウザで遊ぶ
npm run verify   # 設計の主張を実ブラウザで実測
npm run build
```

## なぜこの形なのか

v0.13 まではまったく別のゲームだった（見下ろしの縦スクロール、2軸のドラッグ、
グレイズ倍率、100ステージ）。**丸ごと作り直した**。旧版は
[`v0.13-topdown-keep`](../../tree/v0.13-topdown-keep) ブランチにそのまま残してある。

作り直した理由はひとつ。**位置合わせがあるかぎり、失敗が必ず
「3px 左にいれば助かった」になる。**だから失敗が悔しく、目を離せず、気を張る。

| | 旧版 | いま |
|---|---|---|
| 指がやること | 座標を合わせ続ける | 押す／離す |
| 失敗の原因 | あと3px | どっちを見るか間違えた |
| 触る場所 | 下段のパッド | **画面のどこでも** |
| 1回の長さ | 60〜90秒 | 20〜40秒 |

指が座標を持たなくなったので、操作パッドという区画そのものが要らなくなり、
**ゲーム画面が縦いっぱいに使えるようになった**。速さの体感はほぼこれで決まる。

## 画面

```
┌──────────────┐
│  バナー広告   │  ネイティブ。指の来ない最上部だけ
├──────────────┤
│  くつ    スコア │  HUD 14px。ラベル文字は使わない
├──────────────┤
│              │
│   前方の帯    │  横から見た参道。鹿が右から歩いてくる
│              │  並木は帯より高い（空を埋めるため）
├──────────────┤
│   足元の帯    │  **真上から見た**地面。フンが右から流れる
│              │  靴も真上から
└──────────────┘
```

上帯と下帯で**視点が違う**のはわざと。目の使い方がそもそも違うからで、
同じ横視点で2つ並べると、視線の切り替えではなくただの分割画面に見える。

視線を切り替えると**仕切りが動く**。ここで絵を拡大縮小しない——
ドット絵を縦に潰すと一発で嘘くさくなる。大きさは常に同じまま、
**見えている範囲（切り取る量）だけ**が変わる。

見ていない側は暗くなるが**真っ暗にはしない**。完全に見えないと
「いつ切り替えるか」が当てずっぽうになって理不尽になる。

## 理不尽にしないための仕掛け

1. **当たりは「重なったか」ではなく「通り過ぎたか」で取る。**
   重なりで取ると判定の幅だけ「あと数px」が生まれ、それはそのまま
   位置合わせの巧拙になる。ここでやりたいのは逆
2. 足元のフンの**縦のばらつきは見た目だけ**。当たりには一切効かない
3. 右端に出たものが届くまで **0.85秒以上**（`leadTime`）。
   速さを上げても縮まないので、難しくするときは間隔だけを詰める
4. **きわどい二連をわざと作る**（`clashChance`）。鹿を先に出し、
   フンが **0.75秒後**に着くよう時刻で逆算する（反応時間0.45秒＋戻す余裕）。
   落ち着けば両方さばけるが、たいていどちらかを食う。
   食うならフンのほうが軽いので、迷ったら前を見るのが正解
5. **濃さには上限がある。**ふたつを0.55秒離すと決めた以上、
   届く回数の合計は 1/0.55 = 1.82回/秒 を超えられない。
   超えると片方が湧かなくなる（実際そうなって山場が消えていた）
6. **最初の11秒は教える時間。**1つずつゆっくり、重ねず、踏んでも汚れない。
   その場に「▼おす」「▲はなす」を出す
5. **早めに切り替えても普通に避けられる。**ぎりぎりだと「すれすれ」の上乗せが付く。
   床は低いまま、天井だけ用意する
6. 踏んでも即死しない。転んで、立ち上がって、また走る。くつ3つでおしまい

## ファイル

| | |
|---|---|
| `config.ts` | 定数と曲線。仕様書と1対1 |
| `state.ts` | 状態の型と初期化 |
| `game.ts` | 1フレームの更新。遊びの芯は `s.down` の1ビットだけ |
| `render.ts` | 2つの帯の描画 |
| `sprites.ts` | ドット絵（文字列＝ピクセル） |
| `input.ts` | 押す／離すだけ。**座標を一切読まない** |
| `audio.ts` | 矩形波・ノイズの実行時合成（音源ファイル不要） |
| `storage.ts` | 自己ベストと音の設定（localStorage＋ネイティブ） |
| `main.ts` | 起動・ループ・画面遷移 |

素材ファイルはゼロ。ビルド出力は index.html + js のみで **完全オフライン**。
